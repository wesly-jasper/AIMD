# AIMD Sentinel

Check a photo or video for signs of editing or AI generation. Sign up, drop a
file, and read the result in plain words, with the edited areas masked on the
image, a likelihood-ratio statement of how strong the evidence is, and a
report you can hand to someone else.

A result is evidence, not a ruling: "no signs found" never means "authentic",
and a check that could not run says so instead of reporting nothing found.
**Every verdict is advisory** until the detectors pass independent evaluation;
the result page and every report say so.

Built for the **Nebius x NVIDIA Global AI Hackathon 2026**, track *Best Apps and Agents*.

## The problem

Journalists, moderators and investigators are asked "is this picture real?"
every day. The tools they reach for either return a single confident
percentage with no account of how it was reached, or a heatmap nobody can
interpret. Both overclaim: a detector score is not a probability, and a model
that has never seen a generator says nothing about its images.

AIMD answers two separate questions, *was this file edited after capture?*
and *was it generated by a model?*, from detectors whose limits have been
measured, shows **where** an edit is, and says how much each answer can be
trusted.

## How NVIDIA Nemotron and Nebius Token Factory are used

The **Investigation** panel runs an agent on
**`nvidia/nemotron-3-super-120b-a12b`** through the **Nebius Token Factory**
OpenAI-compatible API (`https://api.tokenfactory.nebius.com/v1/`,
native tool calling). It reads one finished analysis and writes a summary an
examiner can check line by line.

- **It reads, it never decides.** Eight allowlisted tools with strict JSON
  schemas: overview, detections (scores, region boxes, mask summary),
  observations and findings, similarity matches, sources, provenance timeline,
  metadata, and `verify_source_match`. The only argument any tool takes is one
  URL. The agent cannot change a verdict.
- **Every sentence is grounded.** The summary must cite the tool calls each
  sentence rests on. Every URL, number and timestamp is checked against the
  tool results; anything that does not appear there is removed and listed. A
  sentence that cites nothing is flagged in the UI.
- **No private data leaves for nothing.** GPS fields are withheld, the model
  never sees file paths, hashes or raw detector metadata, and analyses are
  owner-scoped.
- **Bounded.** At most 8 model calls, 60 s and 10 investigations per account
  per hour (counted from the database), so public demo traffic cannot drain
  credits. Without `NEBIUS_API_KEY` the panel reports UNAVAILABLE and the rest
  of the system runs unchanged.

Code: `backend/app/services/agent/` (`nemotron_agent.py`, `tools.py`, `grounding.py`).

## What it does

| Question | How | Shown as |
|---|---|---|
| Edited after capture? | **TruFor** localisation (per-pixel map + integrity score), corroborated by a copy-move detector | Verdict, evidence strength, and a **manipulation mask** over the edited areas |
| Generated by a model? | **B-Free** (baseline, decides), UnivFD shown for reference only (never votes) | A separate verdict, never folded into the editing one |
| How strong is the evidence? | Likelihood ratios from calibrations fitted on a validation split (`backend/calibration/fusion-calibration.v4.json`, checksummed) | "68 to 73 times more probable if edited", a range from fully dependent to independent |
| Where did it come from? | C2PA Content Credentials checked against the official trust list; Wikimedia Commons and Internet Archive lookups; similarity to earlier uploads | Declared origin, "altered after signing", provenance timeline |
| What happened to the evidence? | Content-addressed artefacts with sha256, a hash-chained audit log | JSON / Markdown / HTML reports, print to PDF |

## How reliable is it

Measured on labelled sets with a frozen holdout that no detector or rule was
fitted or tuned on (`backend/evaluation/holdout.lock.json`). Full numbers,
confidence intervals and failure analyses: `docs/RELIABILITY_REPORT.md`.

- **Good:** finding and outlining local edits in ordinary photos. TruFor
  caught 80% of controlled edits at an 8% false-alarm rate (AUC 0.91), and
  outlined the right area (mean pixel F1 0.87). Results are exactly
  repeatable.
- **Weak:** small generative inpaintings (34% detected at 256 px) and AI-image
  detection on generators far from B-Free's training data. On the frozen
  holdout B-Free missed 45% of AI images, so "AI generation not indicated"
  means little.
- **Not usable yet:** video manipulation. The result page says so instead of
  reporting "nothing found".

That is why verdicts are labelled advisory. What would change it is listed in
`docs/RELIABILITY_REPORT.md` §5.

## Layout

```
backend/            FastAPI API (Python 3.11)
  app/
    api/v1/endpoints/   auth, media, analysis, cases (folders), audit, system
    core/               settings, auth, rate limits, health, logging
    db/                 models, repository (owner-scoped queries)
    services/           ingestion → preprocessing → detection → fingerprinting
                        → similarity → provenance → evidence → fusion, run by
                        orchestration/analysis_pipeline.py; agent/ (Nemotron);
                        audit/ hash chain
  calibration/          versioned likelihood-ratio calibrations
  evaluation/           frozen holdout lock
  scripts/              model fetchers, benchmark builders, evaluate.py
  tests/                unit/ and integration/
web/                React 19 + TypeScript + Vite app
docs/               reliability report, methodology, security, API, deployment
```

## Run

```bash
# One-time: Python 3.11 venv, dependencies and model weights (see docs/DEPLOYMENT.md)
python -m venv .venv && .venv/Scripts/python -m pip install -r backend/requirements.txt
cd backend
../.venv/Scripts/python scripts/fetch_models.py           # TruFor (research / non-profit licence)
../.venv/Scripts/python scripts/fetch_bfree.py            # B-Free (research / non-profit licence)
../.venv/Scripts/python scripts/fetch_univfd.py           # UnivFD + CLIP (MIT)
../.venv/Scripts/python scripts/fetch_c2pa_trust_list.py  # C2PA trust anchors
../.venv/Scripts/python scripts/download_face_landmarker.py

# Settings: copy .env.example to backend/.env, then set at least
#   NEBIUS_API_KEY=...          (Token Factory; enables the Nemotron agent)
#   AIMD_JWT_SECRET=...         (required outside development)

# Backend (from backend/)
../.venv/Scripts/python -m uvicorn app.main:app --port 8000

# Web app (from web/)
npm install && npm run dev        # http://localhost:5173
```

Create an account on the sign-in screen. `GET /health` reports every detector,
whether its weights match the calibration file, and why anything is missing.

## Test

```bash
cd backend && ../.venv/Scripts/python -m pytest -q
cd web && npm run build
```
